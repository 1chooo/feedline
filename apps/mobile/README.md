# mobile

Expo (React Native) template for the ad-service client.

## Run

Expo needs a simulator, Expo Go, or a physical device, so it runs on the host — not in Compose.

From the repo root:

```bash
pnpm --filter mobile dev
```

Or from this directory:

```bash
pnpm dev
```

Point the app at `http://localhost:8080` (or your machine IP from a device). See [apps/backend](../backend) for the API.
